# Documentation Rule

문서(Markdown, Code Comments 등)를 작성하거나 수정할 때 다음 사항을 반드시 준수해야 합니다.

## Emoji Integrity Check
- [ ] 이모지(Emoji)가 깨지지 않았는지 확인합니다. (예: `` 와 같이 표시되는 글자가 없는지 확인)
- [ ] 특히 마스코트 캐릭터의 아이콘이나 상태를 나타내는 이모지가 올바르게 표시되는지 확인합니다.
- [ ] 파일을 저장하기 전에 인코딩(UTF-8) 문제가 없는지 다시 한 번 점검합니다.
- [ ] 이모지가 포함된 문서를 작성한 후에는 반드시 `view_file` 등을 통해 최종 출력 결과를 확인합니다.
